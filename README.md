# path-of-42-hadiths
Проект «The Path of 42 Hadiths» рассматривает сборник имама ан-Навави как звено в цепи передачи сунны: от эпохи фиксации хадисов до современного этапа религиозного образования. Акцент сделан на сохранении аутентичного смысла текстов при адаптации формата подачи к актуальным образовательным потребностям.
